# vollmer_hrv

Python port of part of **HRVTool v1.07** by Marcus Vollmer (MIT, see `LICENSE_HRVTool_Vollmer`).

Ported: `singleqrs` (with `mvqrs_ann`, `mvqrs_checkbeat`, `tma_filter`, `windowed_extrema`), `HRV.RRfilter`, `HRV.SDNN`, `HRV.RMSSD`, `HRV.pNNx`.
Not ported: SDSD, TRI/TINN, DFA, CD, ApEn, LF/HF, Poincare, rrHRV, pattern, GUI, file importers.

Status: skeleton only; code is added step by step.
